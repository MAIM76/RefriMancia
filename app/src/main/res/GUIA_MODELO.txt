GUIA DE ARQUITECTURA - RefriMancia
===================================
La migracion esta completada. Esta guia describe la estructura actual del proyecto.


CLIENTE HTTP  (api/ClienteRetrofit.java)
----------------------------------------
ClienteRetrofit es el unico cliente Retrofit de la app. Es un singleton que:
  - Inyecta automaticamente el token Bearer en cada peticion autenticada.
  - Detecta respuestas 401 (sesion expirada), limpia la sesion y emite el
    broadcast com.example.refrimancia.SESSION_EXPIRED.
  - Omite el token en el endpoint /login.

Uso:
  ClienteRetrofit.obtenerInstancia(context).create(UsuarioService.class)
  ClienteRetrofit.obtenerInstancia(context).create(RecetaService.class)
  ClienteRetrofit.obtenerInstancia(context).create(ComentarioService.class)


SESION  (SessionManager.java)
------------------------------
SessionManager centraliza el acceso a los datos de sesion en SharedPreferences.

  sessionManager.isSessionValid()          // comprueba token + userId
  sessionManager.fetchAuthToken()          // String con el token JWT
  sessionManager.fetchUserId()             // int con el id del usuario
  sessionManager.fetchUserName()           // String con el nombre de usuario
  sessionManager.fetchUserPhoto()          // String con la URL de la foto
  sessionManager.saveAuthToken(token)
  sessionManager.saveUserDetail(id, nombre)
  sessionManager.saveUserPhoto(url)
  sessionManager.clearSession()            // limpia sesion y resetea ClienteRetrofit

Nota: NO pasar token ni userId via Intent entre actividades. Leerlos siempre
desde SessionManager en la actividad o fragmento que los necesite.


REQUESTS  (modelo/request/)
----------------------------
  LoginRequest        -- correo + contrasena
  CorreoRequest       -- correo (para solicitar codigo de recuperacion)
  CambiarPassRequest  -- correo + codigo + nuevaContrasena

Los campos usan camelCase. La serializacion JSON a snake_case la gestiona
@SerializedName en cada clase.

Nota: RegistroRequest ya no existe. El registro usa multipart directamente
en UsuarioService.registrarUsuario(...).


RESPONSES  (modelo/response/)
------------------------------
  Login                    -- token + datos del usuario (via getData() o getters directos)
  Registro                 -- respuesta al registrar un usuario
  RecetaCreada             -- status + idReceta + foto
  Estado                   -- status + message  (recuperacion de contrasena, etc.)
  RespuestaUnica<T>        -- status + data: T  (perfil de usuario, etc.)
  RespuestaPaginada<T>     -- paginacion generica

Acceso a datos de Login:
  login.getToken()
  login.getIdUsuario()
  login.getNombreUsuario()
  login.getImagenPerfil()
  login.getNombreCompleto()
  login.getCorreoElectronico()
  login.getFechaNac()
  login.getData()          // devuelve el objeto entidad.Usuario completo


ENTIDADES  (modelo/entidad/)
-----------------------------
  Usuario     -- modelo completo del usuario (id, nombre, correo, foto, fecha, etc.)
  Receta      -- modelo completo de receta
  Comentario  -- modelo de comentario con autor y fecha


ENDPOINTS  (api/)
-----------------
UsuarioService:
  login(LoginRequest)                                    --> Call<Login>
  logout()                                               --> Call<ResponseBody>
  registrarUsuario(nombre, pass, nombreCompleto,         --> Call<Registro>
                   correo, fecha, imagenPart)
  obtenerPerfil()                                        --> Call<RespuestaUnica<Usuario>>
  modificarUsuario(id, nombre, pass, nombreCompleto,     --> Call<ResponseBody>
                   correo, fecha, imagenPart)
  listarUsuarios(page)                                   --> Call<RespuestaPaginada<Usuario>>
  solicitarCodigo(CorreoRequest)                         --> Call<Estado>
  cambiarContrasena(CambiarPassRequest)                  --> Call<Estado>

RecetaService:
  listarRecetas(page, tipo, search)                      --> Call<RespuestaPaginada<Receta>>
  obtenerReceta(id)                                      --> Call<RespuestaUnica<Receta>>
  listarRecetasPorUsuario(idUsuario, page)               --> Call<RespuestaPaginada<Receta>>
  crearReceta(titulo, ingr, desc, tipo, tiempo, imagen)  --> Call<Receta>
  crearRecetaConRespuesta(...)                           --> Call<RecetaCreada>
  compartirReceta(id)                                    --> Call<ResponseBody>
  eliminarReceta(id)                                     --> Call<ResponseBody>
